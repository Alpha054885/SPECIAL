## 🚀 GitHub par Kaise Upload Karein (2 Easy Ways)

### Option 1: Terminal / Command Line (Super Fast)
Git repository already initialize aur commit kiya ja chuka hai! Bas yeh 3 commands run karein:

1. GitHub.com par jaakar **New Repository** banayein (e.g., `mens-day-gift`).
2. Apne terminal mein yeh commands run karein:
   ```bash
   cd /Users/asiyaimran/.gemini/antigravity/scratch/mens-day-gift
   git remote add origin https://github.com/<YOUR_USERNAME>/mens-day-gift.git
   git branch -M main
   git push -u origin main
   ```

---

### Option 2: GitHub Website par Drag-and-Drop (Bina terminal ke)
1. GitHub.com par **New Repository** banayein.
2. **"uploading an existing file"** par click karein.
3. `mens-day-gift` folder ke saare files aur `assets` folder ko drag karke drop kar dein aur **Commit changes** dabayein!

---

## 🌐 Free Live Link Kaise Banayein (GitHub Pages - Only 2 Clicks!)
Jab repo GitHub par upload ho jaye, toh website ko internet par live karne ke liye:
1. GitHub par apni repository ki **Settings** par jayein.
2. Left menu mein **Pages** par click karein.
3. **Branch** mein `main` select karein aur `/ (root)` chunein, phir **Save** click karein.
4. 1 minute ke andar aapko live link mil jayega:
   `https://<YOUR_USERNAME>.github.io/mens-day-gift/`
5. Ab aap yeh pyara link directly unko bhej sakti hain! 💕
